# Community standards

We want this project to be a respectful place to learn and collaborate. Treat people with patience and respect, assume good faith, and give technical feedback about ideas and code rather than personal traits.

Harassment, discrimination, personal attacks, doxxing, and sustained disruptive behavior are not acceptable in project discussions or contributions.

Maintainers may edit or remove contributions that violate these standards and may restrict participation when needed. To report a concern privately, contact the repository maintainer through the contact methods on the maintainer's GitHub profile. Do not publish another person's private information in an issue or pull request.
